## Up to five proposed guides (business approval required)

1. Auction shipping preparation checklist: deadlines, item measurements, pickup authorization; approve actual workflow and required documents.
2. Parcel vs LTL vs full truckload: selection factors and when to ask the team; no invented weight thresholds or prices.
3. Packaging fragile auction purchases: photos/material examples from approved operations; no damage-proof guarantee.
4. Planning an international auction shipment: destination restrictions and document responsibilities, reviewed by a qualified operations specialist.
5. What to include in a shipping inquiry: pickup/destination, dimensions, item description and timing; do not solicit payment or sensitive records through the public form.

## Search Console checklist (no account or infrastructure action performed)

- Use an existing verified Domain property if available. New DNS verification needs separate approval; this task does not change DNS. Alternatively have an authorized owner approve a URL-prefix property and its verification method. Never publish verification tokens without approval.
- Submit `https://rapidpacknship.com/sitemap.xml` after the approved static release. It contains only nine canonical indexable pages, not aliases, reviews or incomplete legal pages.
- URL Inspection: test all nine pages' live HTML and rendered view; verify declared and Google-selected canonical, crawl availability, correct H1/content and loaded media. Request indexing selectively after meaningful changes.
- Check Page indexing for soft 404s, duplicate canonical selection, blocked resources, accidental noindex and server errors. Keep real unknown URLs at 404; inspect redirect samples.
- Use Rich Results Test and Schema Markup Validator for supported syntax/content; generic Service/Organization markup does not guarantee a Google rich result. No self-serving review stars are expected.
- Establish pre-release 28-day query/page/device/country baseline where data exists. Compare impressions, clicks, CTR, relevant nonbrand queries and qualified leads after 2–4 and 8–12 weeks, accounting for seasonality.
- Monitor mobile Core Web Vitals/CrUX when enough field data exists; record LCP, INP and CLS distributions, not merely local screenshot results. Use controlled Lighthouse runs for diagnostics, not field-performance claims.
- Check sitemap fetch, 404s, redirects, API error rates and form conversion after release. Analytics/event collection and cookie/privacy changes require separate approval; none added here.
